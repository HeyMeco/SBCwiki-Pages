# GFXBench

Kishonti's cross-platform 3D graphics benchmark. Tests render offscreen at a fixed resolution, so the display and vsync don't cap the result. Aztec Ruins uses Vulkan, Manhattan 3.1 uses OpenGL ES 3.1, T-Rex uses OpenGL ES 2.0. Higher is better.
