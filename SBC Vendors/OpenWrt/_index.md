# OpenWrt

![OpenWrt Logo](assets/openwrt/OpenWrt-Logo.png?h=90&f=webp)

OpenWrt is the open-source Linux distribution for routers. The OpenWrt One is the project's first official hardware. OpenWrt designed it and Banana Pi manufactures it.
