# Rockchip RK3668

> **Status:** Upcoming — Rockchip roadmap targets **Q4 2026**. Specifications below are aggregated from the [Rockchip Developer Conference (RKDC)](https://sbcwiki.com/news/articles/state-of-embedded-q4-25/) and may change before release.

Mid-to-high-tier successor in Rockchip's next-generation lineup, between the interim **RK3572** and flagship **RK3688**. Uses Armv9.3 **Cortex-A730** / **Cortex-A530** cores and the **Arm Magni** GPU (G1 Premium class).

## General Specifications
{{% details title="Specs" open=true %}}

| **SoC** | **Rockchip RK3668** |
|---------|---------------------|
| **Process** | 5–6 nm (200K+ DMIPS) |
| **CPU** | 10-core Armv9.3: 4× Cortex-A730 + 6× Cortex-A530 |
| **RAM** | 4-channel LPDDR5 / LPDDR5x / LPDDR6 (up to 100 GB/s) |
| **GPU** | Arm Mali Magni (1–1.5 TFLOPS) |
| **NPU** | 16 TOPS (RKNN-P3) |
| **VPU** | 8K@90fps decoder · 8K@60fps encoder |
