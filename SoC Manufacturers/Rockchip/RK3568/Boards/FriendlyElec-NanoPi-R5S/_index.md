# FriendlyElec NanoPi R5S

The NanoPi R5S is FriendlyElec's compact RK3568 router board, with two 2.5 GbE ports and one Gigabit port. It also has HDMI output and an M.2 slot for NVMe, so it works as a small home server too. It ships with FriendlyWrt, FriendlyElec's OpenWrt build. There is also a NanoPi R5S-LTS variant.
