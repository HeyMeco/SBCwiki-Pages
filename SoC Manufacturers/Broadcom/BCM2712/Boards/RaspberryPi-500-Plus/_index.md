# Raspberry Pi 500+

The Raspberry Pi 500+ is the upgraded Pi 500. It doubles the RAM to 16 GB, populates an internal M.2 slot with a 256 GB NVMe SSD, and uses a low-profile mechanical keyboard with RGB lighting.
