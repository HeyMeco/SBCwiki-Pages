# Minisforum MS-R1

The Minisforum MS-R1 is a mini workstation built on the Cix P1 (sold as CP8180). It boots through UEFI and adds a full-size PCIe x16 slot wired as x8, so it takes a low-profile single-slot GPU or a network card. Two 10 GbE ports and up to 64 GB of LPDDR5 make it popular as an Arm homelab box.
