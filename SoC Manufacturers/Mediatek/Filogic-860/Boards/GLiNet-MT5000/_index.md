# GL.iNet Brume 3 (GL-MT5000)

The GL.iNet Brume 3 (GL-MT5000) is a wired VPN security gateway on the MT7987A. It has no Wi-Fi, three 2.5 GbE ports and a USB 3.0 port, and runs GL.iNet's OpenWrt-based firmware. GL.iNet engineers have submitted support for the `mediatek/filogic` OpenWrt target.
