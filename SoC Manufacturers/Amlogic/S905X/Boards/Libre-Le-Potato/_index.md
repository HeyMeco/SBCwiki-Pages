# Libre Computer Le Potato (AML-S905X-CC)

Le Potato was Libre Computer's first board, funded on Kickstarter in July 2017. It matches the Raspberry Pi 3 Model B+ layout and adds 4K HDR HDMI output. Mainline Linux and U-Boot support it until 2047. The [Sweet Potato](../libre-sweet-potato/) replaces it with USB-C power, DDR4 and UEFI.
