# Libre Computer Das Frite (AML-S805X-AC-V2)

Das Frite is the second-generation [La Frite](../libre-la-frite/). It moves power input to USB-C, which also works as a USB 2.0 device port, and adds a 3.5 mm AV jack with stereo line out and composite video. Libre Computer uses it for its education.libre.computer embedded Linux course. Support runs until 2056. For now it runs Libre Computer's kernel and U-Boot, and upstream support is pending.
