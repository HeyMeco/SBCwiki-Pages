# Libre Computer Solitude Compute Module (AML-S905D3-CM)

The Solitude Compute Module puts the S905D3 into the Raspberry Pi CM4 form factor and works on the CM4 and CM5 IO boards. On those boards the second HDMI port, PCM input and the CM5 IO Board's fan tachometer don't work. The module has no wireless. SDIO is routed out for an external Wi-Fi module. It runs Libre Computer's Linux and U-Boot, and upstream support is pending.
