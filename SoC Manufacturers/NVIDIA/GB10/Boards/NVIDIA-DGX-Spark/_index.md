# NVIDIA DGX Spark

The DGX Spark is NVIDIA's desktop AI computer built on the GB10, released on 13 October 2025. Its ConnectX-7 NIC can link two units into a 256 GB system, which NVIDIA rates for models of about 400B parameters. It runs DGX OS.
