# NVIDIA

![NVIDIA Logo](assets/nvidia/NVIDIA-Logo.png?h=80&f=webp)

NVIDIA makes Arm-based SoCs with its own GPUs, from the Jetson embedded modules to the Grace server CPUs. The GB10 Grace Blackwell superchip, co-developed with MediaTek, brings that line to the DGX Spark desktop AI computer.

## GB10 / DGX Spark

The GB10 Grace Blackwell superchip and the DGX Spark built around it, NVIDIA's desktop AI computer.

{{< taglist SOC-NVIDIA-DGX >}}

## Jetson

Jetson is NVIDIA's embedded line of modules and developer kits for robotics and edge AI: Thor (Blackwell) and Orin (Ampere) are current, Xavier, TX2 and the Tegra X1-based Nano and TX1 are legacy. Each SoC page lists its module variants as parts. All of them run JetPack, NVIDIA's Ubuntu-based Jetson Linux with CUDA, cuDNN and TensorRT.
