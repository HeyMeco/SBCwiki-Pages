# NVIDIA Jetson Xavier NX Developer Kit

The Xavier NX Developer Kit (May 2020, $399 at launch) carries the SO-DIMM Xavier NX module with 8 GB. It boots from microSD and came with an M.2 Wi-Fi card. The Orin Nano Developer Kit replaced it.
