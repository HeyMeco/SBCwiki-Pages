# NVIDIA Jetson Nano Developer Kit

The Jetson Nano Developer Kit (March 2019, $99 at launch) brought CUDA to a Raspberry Pi-priced board. The B01 revision added a second MIPI CSI connector. JetPack 4 is its last supported release, so the Ubuntu 18.04 base no longer gets updates.
