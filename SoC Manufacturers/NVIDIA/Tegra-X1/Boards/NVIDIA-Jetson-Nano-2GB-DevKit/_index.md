# NVIDIA Jetson Nano 2GB Developer Kit

The Jetson Nano 2GB Developer Kit (October 2020, $59 at launch) is a cut-down Nano kit for education. It has 2 GB of RAM, fewer USB ports, HDMI only and USB-C power. Some regions shipped it with a USB Wi-Fi adapter.
