# NVIDIA Jetson TX2 Developer Kit

The Jetson TX2 Developer Kit (March 2017, $599 at launch) puts the TX2 module on a 170 × 170 mm mini-ITX reference carrier, essentially the same carrier as the Jetson TX1 kit. It includes a 5 MP MIPI CSI-2 camera module.
