# Arm AGI CPU SP113012A

The **Arm AGI CPU SP113012A** is the memory-optimized 64-core processor in Arm's new production silicon lineup. By providing maximum memory bandwidth per core (13 GBps/core) and higher boost clock speeds (up to 3.7 GHz), it is ideal for memory-bound AI workloads and large-scale heterogeneous compute environments.
