# Arm AGI CPU SP113012A

The **SP113012A** is the memory-optimized SKU of the Arm AGI CPU, providing maximum memory bandwidth per core (13 GBps/core) and higher clock speeds.

## General Specifications
{{% details title="Specs" open=true %}}

| **SoC** | **Arm AGI CPU SP113012A** |
|---------|---------------------------|
| **CPU** | 64x Arm [Neoverse V3](/docs/soc-manufacturers/arm/#2023) cores <br> 2x 128 SVE <br> 2MB/core L2 cache |
| **Architecture** | Armv9.2 with bfloat16 and INT8 AI instructions |
| **Frequency** | 3.5 GHz Nominal / 3.7 GHz Boost |
| **System Cache** | 128 MB System-Level Cache |
| **RAM** | 12x DDR5 up to 8800 MT/s <br> 13 GBps/core throughput <br> 2 DIMMs per channel |
| **PCIe/IO** | 96x lanes PCIe Gen6 <br> CXL 3.0 Type 3 <br> 6x 1 Gen4 PCIe control lanes |
| **TDP** | 160W - 380W Configurable TDP |
| **Multi-Socket** | 2-Socket Support (Yes) |
