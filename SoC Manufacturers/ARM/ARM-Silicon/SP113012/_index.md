# Arm AGI CPU SP113012

The **Arm AGI CPU SP113012** is the flagship 136-core processor in Arm's new production silicon lineup, purpose-built for next-generation AI-native data centers. It is designed to handle continuous AI inference workloads, orchestrate AI agents, and manage massively parallel tasks with extreme rack-level density.

## SP113012 Specifications & Features
{{% details title="Specs" open=true %}}

| **SoC** | **Arm AGI CPU SP113012** |
|---------|--------------------------|
| **CPU** | 136x Arm [Neoverse V3](/docs/soc-manufacturers/arm/#2023) cores <br> 2x 128 SVE <br> 2MB/core L2 cache |
| **Architecture** | Armv9.2 with bfloat16 and INT8 AI instructions |
| **Frequency** | 3.2 GHz Nominal / 3.5 GHz Boost |
| **System Cache** | 128 MB System-Level Cache |
| **RAM** | 12x DDR5 up to 8800 MT/s <br> 6 GBps/core throughput <br> 2 DIMMs per channel |
| **PCIe/IO** | 96x lanes PCIe Gen6 <br> CXL 3.0 Type 3 <br> 6x 1 Gen4 PCIe control lanes |
| **TDP** | 230W - 420W Configurable TDP |
| **Multi-Socket** | 2-Socket Support (Yes) |
