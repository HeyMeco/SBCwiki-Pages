# Arm AGI CPU SP113012

The **Arm AGI CPU SP113012** is the flagship 136-core processor in Arm's new production silicon lineup, purpose-built for next-generation AI-native data centers. It is designed to handle continuous AI inference workloads, orchestrate AI agents, and manage massively parallel tasks with extreme rack-level density.
