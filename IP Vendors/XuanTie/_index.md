# XuanTie

## Summary

XuanTie is the RISC-V processor IP brand of Alibaba's DAMO Academy, originally developed by its chip unit T-Head (Pingtouge). It licenses application cores (C-series) and microcontroller cores (E-series) to SoC vendors such as Allwinner and Sophgo, where they serve as the main CPU or as an auxiliary MCU next to Arm cores.

## CPU Cores
